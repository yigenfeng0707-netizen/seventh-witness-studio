## 一句话

从“一章可玩”升级为**两章奇案集 + 警衔成长 + 困难模式 + 成绩卡**，并把线上可靠性做成可验证的工程闭环。

## 新增内容

- **第二章《狱中忏悔信失踪案》**：沈墨白入狱后寄出的忏悔信在邮路上失踪；4 名新嫌疑人、5 件证物、4 条线索、独立真相链。第一章“出三倍工钱的买家”在这里回收——真凶是当铺老板贾万通。
- **侦探警衔**：见习 → 三级 → 二级 → 一级 → 高级 → 首席，六阶；声望由评级累积，跨局保存。二级开局 +5 分钟，高级全员 +5 信任。
- **困难模式**：45 分钟、全员信任 -10、追加红鲱鱼证物；以 S/A 通关解锁。
- **侦探成绩卡**：结案后生成评级/案件/用时/线索/警衔卡片，可保存分享。
- **开局卷宗 + 30 秒玩法引导**：第一眼看到案情、目标与规则，不再“点开不知道干什么”。
- **HUD 增强**：剩余时间旁直接显示线索进度 `0/4`，≤10 分钟红色警告；提问后显示信任变化 `+3/-5`。

## 工程加固（评委看不到，但决定现场是否翻车）

- **37 项回归测试**：两章 × 两难度 × 五种结局 × 存档/警衔/成绩卡；GitHub Actions 测试失败即阻断部署。
- **部署后公网冒烟**：自动等待新容器（`VERSION` build 标记），依次跑 `开局 → 提问 → 出示证据 → 第二章 → 指认 → 成绩卡`，任一环报错即红。
- **LLM 韧性**：单次超时 10 秒、失败不重试；同一供应商连续失败 2 次冷却 60 秒；全链失败仍回退离线规则，游戏不断线。
- **修复的线上问题**：提问 `fame` 参数崩溃、第二章指认名单不切换、成绩卡 Linux 字体缺失、存档读取 typo、切案时卷宗被问候覆盖。
