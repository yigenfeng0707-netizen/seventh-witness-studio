# 《第七位证人》参赛方案

> AI+∞ 开发者创作大赛 第三期「AI 造游戏」（魔搭 ModelScope × Qoder × 盛趣游戏）

## 一、概念（一句话）

**把“AI 的记忆”做成核心玩法的限时审讯推理游戏。**

玩家扮演外来侦探，限时 60 分钟（游戏内时间）审讯 4 名由大模型驱动的嫌疑人；
出示证据撬开他们的记忆与谎言，最终从 5 人中指认真凶。
每个 NPC 拥有：**持久记忆、性格人设、隐藏秘密、信任度与情绪**；
右侧“记忆图谱”实时可视化 NPC 记得什么、隐瞒什么——**AI 不是黑盒，而是玩法本身**。

## 三、真相链（剧本核心）

**真凶：钟表匠 沈墨白（不在审讯名单上的“第七位证人”）**

- 化名“陈”住进苏眉酒馆，打探钟楼守夜安排（⌚怀表刻“沈”→ L3）
- 让学徒向王大锤定制“钩爪钥匙”，三倍工钱（📄账本残页 → L4）
- 用蜡模配出十五年前“丢失”的第三把侧门钥匙
- 案发夜 23:47 提工具箱从侧门潜入，拆走机芯 → 午夜钟声少敲一下（🕯️蜡烛残段逼老周承认打盹 → L1）
- 被蹲守走私案的侦探陆离撞见背影（🧤湿手套 → L2）

4 条关键线索 L1–L4，分别由“对应证据 × 对应 NPC”解锁；解锁数决定结局评级（S/A/B）。

## 四、玩法循环

```
选择审讯对象 → 自由提问/快捷提问(-1min) → NPC记忆图谱更新
     ↑                    ↓
     └──── 指认真凶 ← 出示证据(-2min) → 命中=撬开秘密+关键线索
                                        未命中=NPC 反感
```

- 时间耗尽 → 强制结案（TIMEUP 结局）
- 指认错误 → 冤案结局（真相复盘）
- 指认正确 → 按线索数评级 S/A/B

## 五、技术方案

- **Gradio Blocks** 单应用（魔搭创空间原生支持，点开即玩）
- **LLM 双通道**：魔搭 API-Inference（Qwen，OpenAI 兼容）在线生成台词；离线 **MockLLM 规则兜底** → 评审现场永不断线
- **NPC 引擎**：信任/情绪/记忆状态机 + 证据质询强制剧情 + JSON 结构化输出
- 证据系统：5 件证物 × 4 名 NPC，有效组合才触发坦白
